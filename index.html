How to Play

Get set, start together, and finish as fast as you can.

  1. Add a photo for each player if desired.
  2. Enter each player's name.
  3. Make sure everyone is ready.
  4. Click Start Race to start the shared timer.
  5. Complete the assigned question or task.
  6. Click I Finished! immediately after completing it.
  7. Check the leaderboard for the final rankings.
Race controls
Pause: Freeze the timer and temporarily disable unfinished players' finish buttons.
Resume: Continue from the exact elapsed time. Paused time is not counted.
Reset Round: Clear finish times and rankings and return to ready mode. Player photos stay in place. Names become editable again.

Photo privacy: Images are processed locally in this browser and are never uploaded.
